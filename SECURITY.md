# Security policy

This repository is a sample, not an officially supported Tricentis product. It has no
supported versions or release line: only the latest commit on `main` gets fixes, on a
best-effort basis.

## Reporting a vulnerability

Please **don't** report security vulnerabilities through public GitHub issues, pull requests,
or discussions.

Report them privately instead: open the repository's **Security** tab and click
**Report a vulnerability**. Include:

- what you found and where (file, line, workflow step)
- the steps to reproduce it
- the impact you expect

If you accidentally exposed a Tosca Cloud client secret or a GitHub token while using this
sample, revoke or rotate it right away. Don't wait for a reply.
